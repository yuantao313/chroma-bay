# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests.
Please search the existing issues before filing a new one:

<https://github.com/yuantao313/chroma-bay/issues>

## Support policy

这是个人项目，按「尽力而为」的方式维护，不提供商业支持。

本项目派生自 Microsoft 的 RP2040 Macropad LampArray 示例
（[microsoft/RP2040MacropadHidSample](https://github.com/microsoft/RP2040MacropadHidSample)，MIT）。
针对**本 fork** 的问题请提到本仓库；上游示例本身的问题请提到上游仓库。

Microsoft 对本项目不提供任何支持。
